# CNVista

A purity-ploidy calibrated tool for genome-wide visualization of copy number alterations.

CNVista generates genome-wide visualizations from copy-number ratio data and segmented copy-number calls.

The tool incorporates sample purity and ploidy information to calibrate the baseline representation of copy-number signals.

It provides genome-wide coordinate mapping and classification of copy-number states for visualization.

The tool also supports visualization of allele-specific information, loss-of-heterozygosity annotations, and sex-chromosome dosage.

The repository will be updated with the tool implementation and documentation as the software is prepared for formal release.
